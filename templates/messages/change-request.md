# 변경 요청 답변 (고객사에 올리는 글)

기준선 이후 고객사 요청이 확인된 SRS에 없거나 다를 때 쓴다. 고객 소통 도구에 붙여 넣고 `[ ]`를 채운다. 범위·일정·비용 판단은 결정 권한이 있는 사람이 확인한 뒤 보낸다.

---

**제목**: [요청 요약] 변경 요청 검토 결과 (CR-[번호])

요청하신 [요청 요약]을 검토했습니다.

- 지금 확인된 내용: [페이지 링크] (버전 [YYYY-MM-DD])의 [규칙 번호]: [지금 규칙 한 줄]
- 요청하신 내용: [요청 한 줄]

**영향**

| 항목 | 내용 |
| --- | --- |
| 바뀌는 규칙 | [규칙 번호와 바뀐 뒤 규칙] |
| 일정 | [영향 없음 / N일 추가] |
| 비용 | [없음 / 견적] |

**선택해 주세요**

1. 이번 출시에 반영 ([일정·비용 조건])
2. 다음 출시에 반영
3. 지금 규칙 유지

답을 주시면 문서를 새 버전으로 고치고 다시 확인을 부탁드리겠습니다.
