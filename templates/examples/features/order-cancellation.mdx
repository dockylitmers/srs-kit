## 목적

고객은 결제한 주문을 앱의 주문 상세 화면에서 직접 취소하고, 결제한 카드로 환불받는다. 고객이 직접 취소할 수 없는 주문은 관리자가 관리자 화면에서 환불한다.

## 포함

- 고객의 주문 전체 취소(앱 주문 상세 화면)
- 카드 결제 취소로 환불
- 쿠폰과 포인트 되돌려 주기
- 관리자 환불(고객이 직접 취소할 수 없는 주문)
- 취소·환불 완료 알림(앱 푸시, 이메일)

## 이번 출시에 없는 것

- 주문 일부 취소: 고객은 주문 전체만 취소할 수 있다. 상품 일부 환불은 관리자 환불로 처리한다.
- 계좌 환불과 현금 환불: 결제를 카드로만 받으므로 환불도 카드 결제 취소로만 한다.
- 취소 수수료: 이번 출시에서는 받지 않는다.
- 취소 사유 통계 화면

## 규칙

| ID | 규칙 | 출처 |
| --- | --- | --- |
| CAN-01 | 주문 상태가 `결제 완료`이면 고객은 결제일을 1일째로 세어 7일째 23:59(한국 시간)까지 주문 전체를 취소할 수 있다. 아니면 주문 상세에 취소 버튼 대신 "고객센터로 문의해 주세요"를 보여 준다. | SRC-002, SRC-009 |
| CAN-02 | 주문 상태가 `발급 완료`이면 고객은 취소할 수 없고 관리자만 환불할 수 있다. 아니면 CAN-01을 따른다. | SRC-002 |
| CAN-03 | 환불 금액은 고객이 카드로 결제한 금액 전액이다. 쿠폰 할인액과 사용한 포인트는 환불 금액에 넣지 않고 CAN-04, CAN-05에 따라 되돌려 준다. | SRC-003 |
| CAN-04 | 취소할 때 쿠폰의 유효기간이 남아 있으면 쿠폰을 원래 유효기간 그대로 되돌려 준다. 아니면 되돌려 주지 않는다. | SRC-003 |
| CAN-05 | 취소할 때 사용한 포인트를 모두 되돌려 준다. 포인트의 유효기간이 지났으면 되돌려 준 날을 1일째로 세어 (제안) 30일째 23:59까지 쓸 수 있다. 아니면 원래 유효기간을 따른다. | SRC-005 |
| CAN-06 | 취소가 끝난 뒤 취소 완료 화면에 "카드사에 따라 영업일 3~7일 안에 환불됩니다"를 보여 준다. | SRC-004 |
| CAN-07 | 관리자가 `운영자` 또는 `최고 관리자` 역할이면 환불할 수 있다. 아니면 환불 버튼을 보여 주지 않는다. 환불할 때 사유를 목록에서 골라 남기고, 처리한 사람과 시각을 기록한다. | SRC-006 |
| CAN-08 | 취소나 환불이 끝나면 고객에게 앱 푸시와 이메일로 알린다. 고객이 앱 푸시를 껐으면 이메일만 보낸다. 아니면 둘 다 보낸다. 이메일 아래에는 고객센터 연락처와 운영 시간 (준비 필요)을 넣는다. | SRC-007 |

### 상태 전환

| 지금 상태 | 누가 | 무엇을 | 다음 상태 |
| --- | --- | --- | --- |
| `결제 완료` | 고객(CAN-01 기한 안) | 취소 | `취소 완료` |
| `결제 완료` | 관리자 | 환불 | `환불 완료` |
| `발급 완료` | 관리자 | 환불 | `환불 완료` |
| `발급 완료` | 고객 | 취소 | 허용하지 않음 |
| `취소 완료`, `환불 완료` | 누구나 | 취소, 환불 | 허용하지 않음 |

## 예시

| 예시 | 규칙 | 상황 | 행동 | 결과 |
| --- | --- | --- | --- | --- |
| E1 | CAN-01 | 10/1 14:00 결제, `결제 완료` | 고객이 10/7 23:59에 취소 | 취소된다 |
| E2 | CAN-01 | 10/1 14:00 결제, `결제 완료` | 고객이 10/8 00:00에 주문 상세를 연다 | 취소 버튼이 없고 "고객센터로 문의해 주세요"가 보인다 |
| E3 | CAN-01 | 10/1 23:59 결제, `결제 완료` | 고객이 10/7 23:59에 취소 | 취소된다(결제 시각과 상관없이 결제일이 1일째) |
| E4 | CAN-02 | `발급 완료` | 고객이 주문 상세를 연다 | 취소 버튼이 없다 |
| E5 | CAN-03, CAN-04, CAN-05 | 상품 30,000원, 쿠폰 5,000원 할인(유효기간 남음), 포인트 2,000P 사용, 카드 23,000원 결제 | 고객이 취소 | 카드 23,000원 환불, 쿠폰과 2,000P를 되돌려 준다 |
| E6 | CAN-04 | 쿠폰 유효기간 10/5 23:59까지 | 고객이 10/6에 취소 | 쿠폰을 되돌려 주지 않는다 |
| E7 | CAN-05 | 포인트 유효기간 10/5 23:59까지 | 고객이 10/6에 취소 | 2,000P를 되돌려 주고 (제안) 11/4 23:59까지 쓸 수 있다 |
| E8 | CAN-06 | 카드 결제 주문 | 고객이 취소 | 취소 완료 화면에 "카드사에 따라 영업일 3~7일 안에 환불됩니다"가 보인다 |
| E9 | CAN-07 | `고객 지원` 역할 관리자 | 주문 상세를 연다 | 환불 버튼이 없다 |
