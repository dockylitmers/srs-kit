# 지시서: SRS 문서 사이트 세션

`[ ]`를 채워 작업 세션에 그대로 준다. 기준은 srs-kit `web/README.md`다.

## 목표
[앱 경로](Next.js + fumadocs)에서 `docs/srs`를 언어 전환(한국어·영어)과 페이지별 버전 드롭다운으로 보여 준다.

## 할 일
1. `srs init <저장소> --web [앱 경로]`로 사이트 파일을 복사한다(있는 파일은 건너뛴다). 건너뛴 파일은 web/README.md의 설명대로 합친다.
2. `features/srs-docs/srs-docs.config.ts`에 문서 주소, 사이트 제목, 기준 버전을 넣는다.
3. `source.config.ts`의 frontmatter 스키마와 `srsVersions` 컬렉션을 합친다.
4. 확인: 두 언어, 예전 버전(임시로 bump해 확인 후 되돌림), 영어 없는 페이지, 영어가 오래된 페이지.

## 완료 조건
- 프로젝트의 lint·type-check·테스트·빌드 통과. 문서 라우트가 정적 생성된다.
- 한국어 현재 페이지의 기존 주소가 그대로 열린다.

## 금지
- `docs/srs` 본문 수정(동작 확인용 임시 수정은 되돌린다).
- 커밋·push·PR (승인 권한자가 한다).

## 산출물
- 작업 트리 변경(미커밋), 보고서 [경로]: 바뀐 파일, 검증 결과(명령과 결과, 캡처), 남은 문제.
