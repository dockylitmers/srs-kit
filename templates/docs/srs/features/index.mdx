기능 하나에 한 페이지씩 있다. 각 페이지는 같은 순서로 쓴다.

| 절 | 내용 |
| --- | --- |
| 목적 | 누가 무엇을 할 수 있게 되는지 |
| 포함 | 이번 출시에 들어가는 것 |
| 이번 출시에 없는 것 | 이번에 하지 않는 것 |
| 규칙 | 규칙 하나에 ID 하나 |
| 예시 | 실제 값으로 본 규칙(경계값 포함) |
| 화면 | 실제 화면 캡처 |
| 확인 요청 | 고객사가 정할 것과 제안값 |
| 확인 기록 | 고객사가 어느 버전을 언제 확인했는지 |
| 개발 근거 | 개발팀 참고용. 고객사 확인 대상이 아니다 |

기능 목록은 왼쪽 메뉴에 있다. 페이지별 확인 현황은 [확인 기록](../baseline/confirmations)에 있다.
