There is one page per feature. Every page uses the same sections in the same order.

| Section | What it holds |
| --- | --- |
| Purpose | Who can do what with this feature |
| In scope | What this release includes |
| Not in this release | What this release does not include |
| Rules | One ID per rule |
| Examples | The rules with real values, including boundary values |
| Screens | Captures of the real screens |
| Open questions | What the client needs to decide, with a proposed answer |
| Confirmation record | Which version the client confirmed and when |
| Developer notes | For the development team. Not part of client confirmation |

The feature list is in the left menu. Confirmation status per page is on the [Confirmations](../baseline/confirmations) page.
