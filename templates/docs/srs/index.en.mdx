This is the software requirements specification (SRS) for {{PROJECT_NAME}}. What the client has confirmed feature by feature defines the release scope.

> If the product behaves differently from what the client confirmed, it is a **bug**. If something is not in this document, it is a **change request**.

The Korean pages are the original. If the two languages differ, the Korean page is correct.

## Versions

Each page has its own version (a date). Use the dropdown under the title to read earlier versions. Client confirmations record which version of which page was confirmed.

When several pages change together, they are released as one edition. Every page in an edition gets the same version date.
