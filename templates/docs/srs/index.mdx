이 문서는 {{PROJECT_NAME}}의 요구사항 명세서(SRS)다. 고객사와 기능별로 확인한 내용이 출시 범위의 기준이다.

> 고객사가 확인한 내용과 다르게 동작하면 **버그**, 이 문서에 없으면 **변경 요청**으로 처리한다.

기준 관리 페이지([확인 기록](./baseline/confirmations), 변경 요청, 추적표, 출처 목록, 구현 상태)는 프로젝트 팀이 관리한다.

## 버전

페이지마다 버전(날짜)이 따로 있다. 제목 아래 드롭다운에서 예전 버전을 볼 수 있다. 고객사 확인은 "어느 페이지의 어느 버전"으로 기록한다.

여러 페이지를 한 번에 고칠 때는 판으로 묶어 낸다. 한 판에 들어간 페이지는 모두 같은 날짜 버전이 된다.

## 표시

| 표시 | 뜻 |
| --- | --- |
| `(제안)` | 프로젝트 팀이 제안한 값. 고객사가 확정한다 |
| `(준비 필요)` | 고객사가 만들거나 보내야 하는 것(콘텐츠, 계정, 법적 문구, 연락처) |
