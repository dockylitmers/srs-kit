## 판정 규칙

| 상황 | 처리 |
| --- | --- |
| 확인된 버전과 다르게 동작한다 | 버그. 개발팀이 고친다 |
| 확인된 버전에 없는 것, 확인된 것과 다른 것을 원한다 | 변경 요청. 이 페이지에 등록한다 |
| 문서가 두 가지로 읽힌다 | SRS 결함. 해석안을 고객사에 확인받아 고치고, 구현이 다르면 버그로 처리한다 |
