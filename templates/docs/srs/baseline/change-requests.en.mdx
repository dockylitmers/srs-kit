## How requests are judged

| Situation | Handling |
| --- | --- |
| The product behaves differently from the confirmed version | Bug. The development team fixes it |
| The client wants something that is not in, or differs from, the confirmed version | Change request. Register it on this page |
| The document can be read in two ways | SRS defect. Confirm one reading with the client, update the page, and treat differing behaviour as a bug |
